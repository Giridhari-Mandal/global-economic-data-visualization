# Global Economic Data Visualization

A Data Analyst portfolio project using Python and World Bank economic indicators.

## Objectives
- Compare GDP across 50 countries
- Compare population across 50 countries
- Compare annual inflation rates
- Explore GDP-population relationships
- Examine correlations between economic indicators

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook

## Data source
World Bank World Development Indicators:
https://data.worldbank.org/

The notebook retrieves:
- GDP (current US$): `NY.GDP.MKTP.CD`
- Population, total: `SP.POP.TOTL`
- Inflation, consumer prices (annual %): `FP.CPI.TOTL.ZG`

## How to run
1. Install dependencies:
   `pip install pandas numpy matplotlib jupyter`
2. Open the notebook:
   `jupyter notebook`
3. Run all cells.
4. The notebook retrieves the selected year's data through the World Bank API.
